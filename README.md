# Nordic Trails UI

Act as an expert UI/UX developer. Build a premium, dark-mode frontend for a travel booking website called "Finland Northern Areas Booking" (FNAB). The aesthetic must be Awwwards-level: cinematic, sleek, using high-quality nature imagery, sophisticated typography, and smooth scroll-driven animations (using Tailwind CSS and Framer Motion).

Scope of Work Create a purely frontend React application with the following views:

1. Landing Page

Hero Section: Full-viewport dark cinematic forest/nature background. Large, elegant typography (e.g., "EXPLORE NATURE'S HIDEAWAYS").

Search Bar: A sleek, glassmorphic floating bar to input check-in/check-out dates and guest count, with a "Book Now" CTA.

2. Property Selection Page

Grid Layout: Display various Finnish houses (e.g., Glass Igloos, Log Cabins).

Cards: Each card needs a high-quality image, title, price per night, and a "Select" button.

3. Booking Details & Checkout Form

Form Fields: Clean, minimalist input fields for First Name, Last Name, Email, and Phone Number.

Submit Action: A prominent "Confirm Booking" button.

Conflict UI State: Build a specific error modal triggered if dates are unavailable. The popup must have a red accent and read: "Booking Unavailable: You cannot enter any further because there are no reasonable slots available in our system for these dates." It should disable the confirm button until resolved.

Technical Constraints

Focus strictly on UI components, layouts, and responsive design.

No backend database integration is required; mock all data, states, and the email submission action.
